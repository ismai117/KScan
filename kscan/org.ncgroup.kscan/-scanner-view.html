kscan/org.ncgroup.kscan/ScannerView

ScannerView

@Composable
fun ScannerView(codeTypes: List<BarcodeFormat>, modifier: Modifier = Modifier.fillMaxSize(), cameraId: String? = null, scannerController: ScannerController? = null, filter: (Barcode) -> Boolean = { true }, autoZoom: Boolean = true, result: (BarcodeResult) -> Unit)

Draws the camera preview and reports the barcodes decoded from it.

The preview is all this draws; controls and overlays are the caller's to build. On web the preview is an HTML element the browser stacks above the Compose canvas, so put them beside it rather than over it.

Parameters

codeTypes

The formats to scan for.

modifier

Applied to the preview. Fills the available space by default.

cameraId

The camera to open, from availableCameras(). null lets the platform choose, preferring a rear-facing camera. Web and desktop only.

scannerController

Drives torch and zoom from your own controls.

filter

Called with each decoded barcode; returning false keeps scanning.

autoZoom

Lets the decoder zoom in on a barcode too small to read. Android only.

result

Called with the outcome. Scanning stops at the first match.
