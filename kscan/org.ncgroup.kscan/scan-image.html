actual fun scanImage(imageBytes: ByteArray, codeTypes: List<BarcodeFormat>, filter: (Barcode) -> Boolean, result: (BarcodeResult) -> Unit)

Scans a still image for a barcode.

Parameters

imageBytes

The image, in any format the platform decodes.

codeTypes

The formats to scan for.

filter

Called with each decoded barcode; returning false rejects it.

result

Called with the outcome. BarcodeResult.OnFailed when nothing matched.
